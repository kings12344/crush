# External integrations checklist

Not connected in this starter:
- Email verification provider.
- Secure authentication and backend API.
- Student verification review workflow.
- Image object storage.
- Video upload/transcoding/streaming provider.
- WebRTC audio/video provider.
- Push notifications (FCM/APNs).
- Payment provider that supports Eswatini and target markets.
- Content moderation service or trained moderation workflow.

Before selecting providers, verify current Eswatini availability, pricing, data location, legal terms, and React Native SDK compatibility.
